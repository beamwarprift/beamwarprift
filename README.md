## BeamWarpRift
Software by **Lionrick333**.

**FleetFoot Engine** — fast, lightweight playback control for HTML5 video and audio. [Repository](https://github.com/beamwarprift/FleetFoot-Engine)

**In development**
- **FastForward Engine** — speed control for offline single-player PC games. [Compatibility database](https://github.com/beamwarprift/Fast-Forward-Engine)
- **FrameFit Engine** — take control of your game's picture: stretch it to fill any screen, place and size it exactly where you want, design your own borders, and keep the mouse pointer right where the picture is. [Compatibility database](https://github.com/beamwarprift/Frame-Fit-Engine)
- **KYSYN** — local code intelligence. [Community, roadmap and reports](https://github.com/beamwarprift/kysyn-community)
